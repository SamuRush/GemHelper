=====================================================================
  ВНЕШНИЕ ЗАВИСИМОСТИ И СИСТЕМНЫЕ КОМПОНЕНТЫ
=====================================================================

JARVIS скомпилирован в автономном режиме (.NET Self-Contained)
и НЕ ТРЕБУЕТ установки .NET 8 SDK или .NET Runtime на компьютере пользователя.

Для полноценной работы отдельных модулей системы могут понадобиться:

1. Microsoft Visual C++ 2015-2022 Redistributable (x64)
   - Необходим для работы нативных библиотек распознавания речи (libvosk.dll)
     и нейросетевого инференса (onnxruntime.dll).
   - Обычно уже присутствует в современных Windows 10/11.
   - Если при запуске приложения возникает ошибка отсутствия MSVCP140.dll / VCRUNTIME140.dll:
     скачайте и установите инсталлятор по ссылке:
     https://aka.ms/vs/17/release/vc_redist.x64.exe
     (или откройте ярлык 'VisualCppRedistributable.url' в этой папке).

2. Голосовой синтез (TTS)
   - Основной режим (Primary, Онлайн):
     Microsoft Edge Neural TTS (голос Дмитрий, ru-RU-DmitryNeural).
     Работает сразу через защищённый WebSocket и не требует никаких системных установок.
   - Офлайн-режим (Offline / Fallback):
     Системный интерфейс Windows SAPI5.
     По умолчанию используется встроенный системный мужской голос 'Microsoft Pavel'.
     Для получения максимально реалистичного мужского тембра в офлайне
     рекомендуется установить пакет Silero SAPI5 ('Aidar (Russian)').
     Подробная инструкция в файле 'SileroSAPI5_Setup_Guide.txt'.

3. Локальная нейросеть LLM (Опционально)
   - Для глубоких диалогов, ответов на произвольные вопросы и умного анализа:
     Установите LM Studio (https://lmstudio.ai), загрузите модель (например,
     Qwen 2.5 1.5B / 7B Instruct) и запустите локальный сервер на порту 1234.
