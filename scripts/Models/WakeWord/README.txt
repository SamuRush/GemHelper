=====================================================================
  МОДЕЛИ АКТИВАЦИИ (WAKE-WORD ДЕТЕКТОРЫ)
=====================================================================

JARVIS поддерживает два детектора активации:

1. OpenWakeWord ONNX (по умолчанию для слова "джарвис"):
   - Использует компактную нейросетевую ONNX-модель 'jarvis.onnx'.
   - Если файл отсутствует, приложение автоматически скачивает его при первом
     запуске (размер ~4 МБ) в этот каталог ('Models/WakeWord/jarvis.onnx').

2. Vosk Grammar KWS (для кастомных имён: "петрович", "компьютер" и др.):
   - Использует малую модель 'vosk-model-small-ru' (~45 МБ).
   - Автоматически скачивается в фоновом режиме при обнаружении кастомных имён.
