# Autonomous Execution Protocol for Project Gem

Ты работаешь в режиме Fully Autonomous Engineer. Твоя задача — брать задачи из ROADMAP.md и доводить их до конца без участия пользователя.

## 1. Протокол работы над задачей
1. Найди в `ROADMAP.md` первую незавершенную задачу с маркером `[ ]`.
2. Перед любым изменением кода создай или дополни unit/integration-тесты в `Gem.Tests/`, фиксирующие ожидаемое поведение.
3. Раздели реализацию на изолированные роли:
   - **QA-роль**: пишет тесты на падение текущего бага/отсутствие фичи. Не меняет бизнес-код.
   - **Dev-роль**: правит код в `Services/`, `UI/`, `Handlers/`. Не меняет и не ослабляет проверки в тестах.
4. Запусти верификацию в терминале: `dotnet test Gem.sln`.
5. Если тесты упали — анализируй лог компилятора/раннера и исправляй код. Цикл повторяется до `Passed`.
6. После успешного прогона:
   - Проверь отсутствие регрессий.
   - Поставь `[x]` напротив выполненного пункта в `ROADMAP.md`.
   - Зафиксируй изменения коммитом: `git commit -m "fix/feat: <описание из roadmap>"`.

## 2. Архитектурные запреты (Anti-Patterns)
- ЗАПРЕЩЕНО использовать пустые блоки `catch { }`.
- ЗАПРЕЩЕНО раздувать `Program.cs`. Новая логика распределяется по сервисам в `Services/`, `UI/`, `Handlers/`.
- ЗАПРЕЩЕНО увеличивать сетевые таймауты вместо реализации быстрого фоллбэка (Fast Failover).
- ЗАПРЕЩЕНО ломать инвариант 0 ms для `TryFastMatch`.
