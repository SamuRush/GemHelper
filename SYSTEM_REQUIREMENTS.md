# Системные требования JARVIS Assistant & HUD

В данном документе приведены минимальные и рекомендуемые системные требования для развертывания, компиляции и комфортной работы голосового ассистента JARVIS со встроенным биоморфным HUD-оверлеем.

---

| Компонент / Ресурс | Минимальные требования | Рекомендуемые требования |
| :--- | :--- | :--- |
| **Операционная система** | Windows 10 x64 (версия 2004 / билд 19041+) | Windows 11 x64 (версия 22H2 / билд 22621+) |
| **Среда выполнения** | .NET 8.0 Runtime (Desktop x64) | .NET 8.0 SDK (x64) |

## 2. Детальная спецификация компонентов

### 2.1. Процессор и векторные инструкции (CPU & AVX2)
- **Обязательное требование:** Наличие инструкций **AVX2 (Advanced Vector Extensions 2)**.
- **Обоснование:** Модели распознавания речи `Vosk STT` (на базе Kaldi) и нейросетевой детектор активационной фразы `OpenWakeWord` (библиотека ONNX Runtime) скомпилированы с оптимизацией под AVX2 для обеспечения сверхнизкой задержки инференса (до 5–15 мс). Без поддержки AVX2 производительность распознавателя резко падает, вызывая запаздывание аудиопотока.

### 2.2. Управление оперативной памятью (RAM) и оптимизация
- **Профиль в простое:** Благодаря пулингу аудиобуферов (`ArrayPool<byte>.Shared`), своевременному освобождению COM-сессий WASAPI (`AudioSessionControl.Dispose()`) и очистке неиспользуемых подписок `CompositionTarget.Rendering`, процесс потребляет строго **150–350 МБ RAM** в фоновом режиме.
- **Ограничения:** В системе должно оставаться не менее 4 ГБ свободной памяти для работы локального сервера инференса (LM Studio / Ollama), загружающего квантованные веса моделей в RAM/VRAM.

### 2.3. Аудиоподсистема (Input / Output / WASAPI Loopback)
- **Устройство записи (Вход):**
  - Поддержка записи звука через Windows Multimedia API / NAudio (`WaveInEvent`).
  - Формат аудио: 16 000 Гц, 16 бит, 1 канал (моно).
- **Устройство воспроизведения (Выход и Loopback):**
  - Активная конечная точка воспроизведения звука по умолчанию (`WasapiLoopbackCapture`).
  - Требуется для работы биоморфного спектрального визуализатора реактора HUD (перехват системного звука, выделение полосы баса 40–180 Гц и детекция ритма).

### 2.4. Графическая подсистема и HUD Overlay (WPF Rendering)
- Окно оверлея (`OverlayWidget`) и векторный реактор (`ArcReactorVisualHost`) используют аппаратный конвейер DirectX WPF.
- Требуется поддержка частоты обновления 60 FPS для плавной кинематики биоморфного «лица ИИ» и световых волн.

### 2.5. Локальный сервер LLM (LM Studio / Ollama)
- **Endpoint по умолчанию:** `http://localhost:1234/v1` (LM Studio OpenAI-совместимый API) или `http://localhost:11434/v1` (Ollama).
- **Рекомендуемые модели:**
  - `qwen2.5-7b-instruct` (оптимальный баланс точности и скорости генерации JSON).
  - `llama-3.2-3b-instruct` (для слабых систем без дискретного GPU).
- При отсутствии запущенного сервера LLM ассистент автоматически переходит на 0 мс детерминированный роутер (`TryFastMatch`) и встроенный локальный парсер.

### 2.6. Клиент Steam и UI Automation
- Установленный и запущенный клиент Steam для управления библиотекой игр.
- Поддержка Windows UI Automation API (`UIAutomationClient` / `AutomationElement`) для защищенного и детерминированного подтверждения параметров установки и лицензионных соглашений (EULA).
