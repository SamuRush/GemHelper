# JARVIS — Project Roadmap & Architecture State

## Архитектурные принципы
- **Fast Command Processing (0 ms, без LLM)**: системные действия, звук, медиа, запуск/установка игр.
- **Cognitive Layer (LLM / LM Studio / Qwen)**: диалог, сложные намерения, FSM-подтверждения.
- **DPI-независимая автоматизация**: Bitmap-сканирование окон без привязки к жестким координатам.

## Фаза 3. Контроль среды (Environmental Control) [В РАБОТЕ]
- [x] **Управление мастер-громкостью Windows (CoreAudioApi via VolumeCommandHandler)**:
  - Прямое управление мастер-громкостью Windows (`IMMDeviceEnumerator`, `IAudioEndpointVolume`).
  - Команды: абсолютный уровень (0–100%), дельта (громче/тише на X%), mute/unmute.
- [x] **Глобальные медиа-клавиши (Play/Pause, Next, Prev, Stop via MediaCommandHandler & MediaKeyService)**:
  - 0 мс быстрый роутинг в `TryFastMatch()` без обращения к LLM и SteamService.
  - Эмуляция `VK_MEDIA_PLAY_PAUSE`, `VK_MEDIA_NEXT_TRACK`, `VK_MEDIA_PREV_TRACK`, `VK_MEDIA_STOP` через Win32 `SendInput` / `keybd_event`.
  - Управление воспроизведением поверх полноэкранных игр и любых медиаплееров (Spotify, Яндекс Музыка, AIMP, браузеры).
- [x] **Таймеры и напоминания (`TimerService.cs` & `TimerCommandHandler.cs`)**:
  - Фоновые асинхронные таймеры (`ITimerService`, `ActiveTimer`, `Task.Delay` + `CancellationToken`).
  - Быстрый парсер в `TryFastMatch()` (< 5 мс, без LLM) с поддержкой чисел, дробей ("полчаса", "полтора часа", "минуту") и меток ("напомни через 15 минут выключить плиту").
  - Голосовое оповещение через `VoiceFeedbackService` («Сэр, время таймера вышло.») с потокобезопасной сериализацией TTS.
  - Команды отмены («отмени таймер») и статуса («сколько осталось»).
